# MIP Competition 2027

This repository holds the organizing materials and tooling for the **MIP Competition 2027:
"Explainability and Small Infeasible Subsystems"**, part of the
[2027 MIP Workshop](https://www.mixedinteger.org/2027).

It will contain the forthcoming solution checker and other project tooling used to evaluate
competitor submissions.

See the [competition page](https://www.mixedinteger.org/2027/competition), for announcement and
rules.
